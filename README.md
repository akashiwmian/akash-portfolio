# AKASH — Personal Academic & Research Portfolio Website

A personal portfolio and scientific research dossier for **AKASH**, Agricultural Engineer and Irrigation & Water Management Researcher at Bangladesh Agricultural University (BAU).

> **Theme**: NATURE × SCIENCE × AGRICULTURAL TECHNOLOGY  
> **Tagline**: *"Advancing Sustainable Agriculture Through Water Science, Research & Technology."*

---

## 🛠️ Technology Stack

- **Framework**: React.js 18 (ES6+ JavaScript, strictly JSX, no TypeScript, no Next.js)
- **Bundler / Tooling**: Vite 5
- **Styling**: Tailwind CSS 3 (Custom palette: Forest Green `#163D2B`, Deep Green `#102B21`, Off-White `#F7F8F3`, Sage Green `#A5B89A`, Water Cyan `#5C9EAA`, Deep Pine `#26352C`)
- **Icons**: Lucide React
- **Typography**: Manrope, Inter, JetBrains Mono

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```

### 4. Preview production build
```bash
npm run preview
```
